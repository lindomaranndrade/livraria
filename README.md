# Livraria

Sistema simples para gerenciamento de livros de uma livraria, desenvolvido como atividade prática de versionamento de código com Git e GitHub.

## Funcionalidades

- Cadastro de livros
- Listagem de livros
- Integração entre frontend, backend e banco de dados

## Tecnologias

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Git e GitHub

## Estrutura do projeto

- backend/ — código responsável pelo processamento e comunicação com o banco de dados.
- database/ — scripts do banco de dados.
- arquivos/ — documentação e arquivos complementares.
- Arquivos HTML — interface do sistema.
